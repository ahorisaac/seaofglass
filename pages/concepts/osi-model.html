The OSI Model

Lesson complete — progress saved.

The OSI model is a postal system for data. Each layer does one job, then hands the parcel to the next layer.

All People Seem To Need Data Processing

You don’t memorise the OSI model to sound clever. You use it to locate problems and attacks. “The cable is fine” is Layer 1. “The IP is reachable but the port is closed” is Layer 4. “The app returns 403” is Layer 7. It turns confusion into a checklist.

Lab: spin the stack, wrap the packet

Focus a layer, then step the packet down the stack. Watch headers get added: data → segment → packet → frame → bits. This wrapping is called encapsulation.

Attacker & defender view

Attackers pick a layer to attack. Defenders monitor layers: firewalls at L3/L4, WAFs at L7, TLS at L6, switches at L2. When troubleshooting, start at L1 and climb — or start at the symptom and drop.
