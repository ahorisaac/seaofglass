The CIA Triad

15 min Reading Lab: pending Quiz: pending

Lesson complete — progress saved. You own the three promises.

Every system makes three promises. Security is simply the art of keeping them.

C = secrets stay secret · I = data stays true · A = systems stay usable

Forget the spy agency. In security, CIA is a memory tool for the three things every computer system promises its users. Break any one of them and you have a security incident. Name which one broke, and you instantly understand the attack.

CConfidentialitysecrets stay secret
IIntegritydata stays true
AAvailabilitysystems stay usable

C Confidentiality — “only the right eyes”

Information is seen only by people allowed to see it. Your medical file, your password, your company's payroll — none of it should leak.

  • Broken by: a password dump, an eavesdropper on café Wi-Fi, a phishing page.
  • Defended by: encryption (AES, TLS), access control, MFA, least privilege.
  • Real example: the 2017 Equifax breach exposed 147 million people's records — a pure confidentiality failure.

I Integrity — “the data tells the truth”

Information is correct and unaltered unless changed by someone authorised. A bank balance, a grade, a software update — it must be exactly what it should be.

  • Broken by: a man-in-the-middle editing a transfer, malware patching a binary, an insider altering logs.
  • Defended by: hashing (SHA-256), digital signatures, checksums, version control, audit trails.
  • Real example: Stuxnet silently changed centrifuge speeds while reporting “all normal” — integrity weaponised.

A Availability — “there when you need it”

The system works when authorised users need it. The most beautiful encryption is useless if the hospital can't open its own records.

  • Broken by: ransomware, DDoS floods, a deleted database, even a cut cable.
  • Defended by: tested backups, redundancy, rate limiting, DDoS protection, patching.
  • Real example: WannaCry (2017) locked NHS computers — appointments cancelled, ambulances diverted.

Read any attack through the triad

Attack C I A Why
Ransomware — ✓ ✓ Files altered (encrypted) and unusable; modern gangs also steal first (C).
DDoS — — ✓ Nothing stolen or changed — the service just drowns.
Password dump ✓ — — Secrets exposed; data itself untouched.
MITM bank edit ✓ ✓ — Traffic read and rewritten in transit.
SQL injection ✓ ✓ ✓ Read, modify or drop entire databases — all three promises at risk.

Memory hook

“Secrets, Truth, Uptime.” Next time you read breach news, ask: which promise broke? Do it five times and the triad is yours forever. As a pentester, every finding you report will be scored by which of these three it threatens.
