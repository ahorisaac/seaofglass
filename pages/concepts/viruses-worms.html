Viruses vs Worms

10 minReading Lab: pending Quiz: pending

Lesson complete — progress saved.

A virus needs a host file and a human action. A worm is standalone and spreads itself across the network.

virus = hitchhiker · worm = explorer

V Virus — the hitchhiker

Infects a host: a document, executable, script or boot sector. It spreads when the host moves — shared files, email attachments, USB drives. It usually needs a person to open, copy or run something.

  • Examples: macro viruses, file infectors, boot-sector viruses.
  • Stops with: attachment filtering, macro hygiene, user training, backups.

W Worm — the explorer

Standalone malware that scans for vulnerable systems and copies itself without user action. Worms can burn through a flat network in minutes because every infected host becomes a new launcher.

  • Examples: Morris (1988), Conficker, WannaCry’s spreading component.
  • Stops with: patching, segmentation, egress filtering, disabling unused services.
Virus Worm
Needs a host file? Yes No
Needs human action? Usually No
Spreads over network by itself? No Yes
Typical speed Human-paced Machine-paced
Best defence Hygiene + training Patching + segmentation

Memory hook

“Virus rides. Worm roams.” If it needs you to double-click, think virus. If unpatched machines start lighting up across a subnet, think worm.

Lab: watch the spread curve

Seed patient zero, then compare propagation. Virus mode infects neighbours only when users make mistakes. Worm mode scans randomly and spreads machine-fast. Patching creates immune hosts; segmentation confines worm outbreaks.
