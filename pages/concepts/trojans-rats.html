Trojans & RATs

12 minReading Lab: pending Quiz: pending

Lesson complete — progress saved.

A trojan is malware wearing a useful disguise. A RAT is a trojan that hands the attacker a remote control.

looks useful → runs hidden → attacker in control

The name comes from the Trojan Horse: the gift looks harmless, so the victim carries it inside the walls. Trojans do not self-replicate like worms. They rely on deception — cracked software, fake installers, game cheats, “urgent” attachments.

T Trojan — the disguise

Pretends to be legitimate: a PDF reader, a codec, a cheat engine, a system update. When run, it installs something malicious instead of (or alongside) the promised function.

R RAT — Remote Access Trojan

A trojan that gives the attacker interactive control: screen capture, file access, keystroke logging, webcam/mic access, command execution. Architecture: controller → C2 → agent on the victim.

Capability What the victim might notice Defender artifact
Screen capture Nothing obvious Suspicious process reading display APIs
Keylogging Nothing obvious Keyboard hook DLL / input capture
File transfer Disk/network spikes Outbound data volume anomaly
Webcam/mic Camera LED (sometimes) Process accessing camera/mic without consent
Persistence Slower boot New Run key / scheduled task / service

The consent line

Remote admin tools (like helpdesk software) are legitimate with consent and visibility. A RAT is the same category of capability without consent. The difference is permission, visibility and intent.
