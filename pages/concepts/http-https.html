HTTP vs HTTPS

12 minReading Lab: pending Quiz: pending

Lesson complete — progress saved.

HTTP is the web’s request/response language. HTTPS is that language inside a TLS envelope.

HTTPS = HTTP + encryption + integrity + server authentication

Every web interaction is a request and a response. A request has a method, path, headers and sometimes a body. A response has a status code, headers and a body. HTTPS does not change HTTP’s meaning — it protects the conversation from being read or altered on the wire.

Code Meaning Memory hook
200 OK “Here you go.”
301 Moved permanently “We moved, update your map.”
401 Unauthorized “Who are you? Log in.”
403 Forbidden “I know you. No.”
404 Not found “No such door.”
500 Server error “The server broke, not you.”

The padlock myth

The padlock means encrypted to this domain, not “this site is trustworthy.” Phishing sites can have valid certificates too. HTTPS protects the pipe, not the intentions of the site owner.
