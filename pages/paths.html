Lab // Build your range

Your first hacking lab — safely.

Run Kali or Parrot inside a virtual machine on your own computer. Isolated, snapshottable, free. Practise only against lab targets you own.

Kali Linux

Attacker's standard

Debian-based, 600+ security tools preinstalled. The industry default for penetration testing.

  1. 1 · Hypervisor — install VirtualBox (or VMware).
  2. 2 · Image — grab the prebuilt VM from kali.org/get-kali , import it, boot.
  3. 3 · Login — default credentials: 
    kali / kali
  4. 4 · Update everything: 
    sudo apt update && sudo apt full-upgrade -y
  5. 5 · Snapshot — take a VM snapshot now. Break things fearlessly, roll back instantly.

Parrot OS

Light & private

Lighter on RAM, privacy-friendly, gorgeous out of the box. A favourite on modest laptops.

  1. 1 · Hypervisor — same as Kali: VirtualBox or VMware.
  2. 2 · Image — download the Security Edition from parrotsec.org .
  3. 3 · Update: 
    sudo apt update && sudo apt full-upgrade -y
  4. 4 · Core tools (Home edition): 
    sudo apt install -y nmap burpsuite metasploit-framework
  5. 5 · Isolate — keep the lab on a host-only network. Never point tools at systems you don't own.
